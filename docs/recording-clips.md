# Recording sample clips / Nghe đúng đoạn để so giọng

VI: Từ bài nghe hoặc lịch sử bản thu, mở mẫu có đoạn đã chọn. Player hiển thị số đoạn và mốc giây, đặt vị trí đầu đoạn sau khi tải metadata và chỉ phát khi người dùng bấm Play. Hết đoạn sẽ dừng; bấm Play lần nữa nghe lại từ đầu đoạn. Tốc độ0.75/1/1.25/1.5 vẫn dùng được. Đổi đoạn sẽ dừng và gỡ player cũ trước khi tải đoạn mới. Mẫu không có đoạn tiếp tục dùng player cả bài.

The authenticated lesson endpoint accepts optional `?segment={id}`. It first applies the existing lesson-version access rules and resolves only that version's matching segment. A missing or cross-version segment returns404 rather than falling back to whole-lesson playback. The `recordingSegment` projection contains only ID, order and StartMs/EndMs; no transcript, accepted answers, disclosure or listening session is created. An ordinary request returns null for that field. Retained owner-only historical sample rights also apply to this read. Playback still uses the ordinary authorized media endpoint and its short-lived grant.

The URL proposes IDs only. Client-supplied timing is ignored; the player uses the server response and rejects a missing/mismatched segment. Metadata seeks without autoplay. Native seeking/time-update events and an animation-frame check enforce the clip's end; seek below its start is clamped. Explicit Play at the end restarts the clip. A grant retry changes the media request and restores the bounded previous position without autoplay. Audio whose duration cannot contain the clip shows an error instead of playing an unrelated range. Unmount stops the captured element and cancels frame work. Existing page-scoped single-player behavior remains in effect.

Two additional relational cases cover the exact four-field timing projection, no transcript leakage or learning/receipt writes, absent/cross-version segments, retained historical-owner access and anonymous/foreign denial. Six frontend cases cover source resolution/change, no whole-lesson fallback, native/animation-frame bounds, speed, no autoplay, teardown and grant retry/duration mismatch. All145 frontend cases and the production build pass. The checks model media events and frames; native decoder timing, mobile/device audition and background-tab precision remain acceptance work. No speech grading, upload or learning completion is added.
