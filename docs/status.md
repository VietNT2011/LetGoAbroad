Vocabulary navigation now opens [personal cards](personal-cards.md); Community remains marked “Sắp có”. Infrastructure profiles alone do not imply that the corresponding product integration works.

[Private recording administration](recording-privacy.md) applies ownership to CMS media/job catalogs and job retry as well as playback; Admin/Editor roles do not grant access to another person's private recording metadata.

[Lesson-sample recording comparison](recording-comparison.md) opens an authorized lesson version alongside local capture/playback with one active page player at a time. An explicit [sample binding](recording-context.md) persists the exact lesson version and optional segment on an owned recording.

[Selected-segment comparison](recording-clips.md) resolves timing without transcript/session writes, bounds playback to that segment and stops the old player when changing sources. Native device/decoder precision remains unverified.

[Private recording reflections](recording-reflections.md) add current raw notes/optional subjective clarity and rhythm levels, ETag conflict comparison, exact unknown-outcome replay and an owner journal retained after audio deletion. [Append-only history](recording-context.md) preserves actual note/source edits and authorized historical sample links. These do not count as objective scores or learning completion; broad device acceptance and account-wide erasure remain open.

## Verification evidence

- SQL Server + Azurite + actual FFmpeg integration suite covers owner isolation, key nondisclosure, CSRF, email lifecycle, concurrency, receipt replay/conflicts, atomic import/answer batches, deadlines, sections, task completion, blob immutability, decode rejection, byte ranges, lease fencing, deletion, retention and retry history.
- SQLite is a supplemental CI/demo profile. UTC tick conversion preserves timestamp precision so replay responses remain stable. Existing SQLite development databases from an older codec are not an upgrade target; use a new disposable SQLite database or SQL migrations.
- Browser checks completed: demo login; mini test, immediate save-then-submit and explanations; packaged app enrollment, lesson quiz, dashboard refresh retaining progress.
- Production npm dependencies were audited and the reported React Router advisory was patched. No measured p95, concurrent-user capacity, call reliability or educational-score validity is claimed.
